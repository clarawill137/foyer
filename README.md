# ✦ Фойе

Своя главная SillyTavern вместо стоковой «Recent Chats» — в стиле «Графит и вино», как Life.

- **«Продолжить»** — большая карточка последнего (или закреплённого) чата: последний кадр из чата фоном, состав, место и время из шапки GC (или из Horae), концовка последнего поста — на чём остановились. Тап — открыть.
- **Группы — тоже большими карточками** (с 0.2): у каждой группы своя карточка как «Продолжить» — её самый свежий чат, все по давности, свежие сверху. В мелком списке группы с коллажами путались.
- **Недавние** — остальные чаты карточками: аватарка (у группы — её фото или коллаж), нормальное имя ветки вместо `2026-06-20@18h13m11s091ms`, концовка поста без HTML/JSON/CSS/плашек/think/заметок.
- **⋯** у любого чата: открыть, закрепить, своё название в Фойе (например «God Complex»), переименовать файл, удалить. Всё делают стоковые кнопки ST — Фойе их только жмёт.
- **Поиск** по чатам, **полка персонажей** (избранные первыми, тап — их последний чат), временный чат, «сколько чатов грузить».
- **Хронограф** (с 0.3, если стоит ядро «Священный таймлайн» и у чатов есть мир): лента 1917–2025 — эпохи мира
  полосами, фиксированные точки ◆ над ними, пустые десятилетия сжаты; лента сама прокручена к эпохе последнего чата.
  Тап по эпохе — карточка: состав, облик персоны, очередь канона (🟡/🚩), **«Войти»** — ядро открывает каноничный чат
  эпохи (группу или чат карточки) и само переключает всё остальное; другие чаты эпохи — там же. Тап по ◆ — событие.
  «Вся лента» — сверху вниз, по годам, тайное помечено 🔒 (это вид автора).
  **«Сыграно»** (0.3.1, ядро 0.9.9+): у события, которое ждёт сцены (финал эпохи или её событие, ещё не отмеченное),
  в карточке кнопка «Сыграно» — отметка в Хронике; у эпохи видно, сыгран ли финал. Ошиблась — «Снять отметку».
- **Все чаты карточки** (с 0.4): тап по персонажу на полке — шторка со всеми его чатами, не только с последним:
  название, сколько сообщений, когда, чем кончился; «текущий» помечен; сверху — «Продолжить последний». У группы то же —
  через ⋯ у её чата → «Все чаты». Чат, которого нет среди недавних, Фойе открывает средствами таверны (как стоковая
  главная), остальные — по-прежнему её же кнопкой.
- **Архив** (с 0.4): «убрать с главной, ничего не удаляя». Чат — через ⋯ → «В архив» или коробкой в списке чатов
  карточки; карточка целиком (со всеми чатами) — «Карточку в архив» в её шторке. Внизу главной появляется «Архив · N»:
  там всё убранное, тап — открыть, стрелка — вернуть. Файлы чатов и карточки не трогаются.
- **Закрепить карточку на полке** (с 0.4) — в шторке карточки; закреплённые стоят первыми, потом избранные таверны.
- **Окна Life** (с 0.4, если стоит Life 0.62+): «Персоны», «Лорбуки», «Расширения», «Подключение» — кнопками на главной;
  им не нужен открытый чат.
- Поле ввода на главной спрятано (оно там всё равно открывает чат с ассистентом) — включается шестерёнкой.
- **Снимки.** Пока чат открыт, Фойе запоминает последний кадр, шапку и концовку поста (в настройках расширения, до 40 чатов) — поэтому на главной видно сцену, даже если последним сообщением в файле лежит лог телефона.

Ничего не шлёт модели. Главная второго запроса к серверу не делает (берёт тот же ответ `/api/chats/recent`, что и ST);
список всех чатов карточки запрашивается только когда открыта её шторка (у группы — по запросу на чат, как у самой таверны).

## Установка

```
docker exec sillytavern sh -c 'cd /home/node/app/data/default-user/extensions && git clone https://github.com/clarawill137/foyer foyer'
```

Потом обновить страницу.

Если Фойе раньше стояло из ветки `foyer` репы LIFE — переставить отсюда (настройки и снимки живут в settings.json, не в папке, — не пропадут):

```
docker exec sillytavern sh -c 'cd /home/node/app/data/default-user/extensions && rm -rf foyer && git clone https://github.com/clarawill137/foyer foyer'
```

## Обновление

```
docker exec sillytavern sh -c 'cd /home/node/app/data/default-user/extensions/foyer && git pull'
```

## Выключить

Расширения → ✦ Фойе → «Своя главная вместо стоковой».
